# 🎓 KVS Certificate Studio

**A smart, professional, and easy-to-use web application for generating KVS CPD certificates.**

KVS Certificate Studio is a web-based certificate generation tool designed to simplify the process of creating, previewing, and downloading individual or bulk certificates.

## ✨ Key Features

- 🎨 Professional certificate design and preview
- 🖼️ Export certificates as high-quality JPEG images
- 📦 Optimized JPEG compression targeting 150–190 KB per certificate
- 🗂️ Bulk certificate generation with ZIP download
- 🖼️ PNG export support
- 📊 Excel/CSV data import
- 🖨️ Print-ready certificate output
- ⚡ Simple and user-friendly interface
- 🌐 Runs directly in a web browser

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML Canvas
- jsPDF
- JSZip

## 🚀 Getting Started

1. Download or clone this repository.
2. Open the HTML file in a modern web browser.
3. Import the certificate data.
4. Preview the certificate.
5. Generate and download your certificates.
